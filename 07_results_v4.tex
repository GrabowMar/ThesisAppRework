\chapter{Results of Study}
\label{ch:results}

This chapter presents the quantitative findings from the \textit{ThesisAppRework} platform described in Chapters~\ref{ch:methodology} and~\ref{ch:platform}. The study evaluated 10 large language models across 20 requirement templates, generating 230 full-stack web applications subjected to automated analysis by 27 tools across four containerized services. Results are organized across eight dimensions: pipeline execution, code volume and defect density, static analysis (14 tools), dynamic analysis (6 tools), performance testing (4 tools), AI-based analysis (3 tools), operational research rankings, and aggregate visualisations.

\section{Operational Research: Model Rankings}
\label{sec:model_rankings}
%=============================================================================

To provide an objective multi-criteria evaluation, two Multi-Criteria Decision Making (MCDM) methods were applied: TOPSIS (Technique for Order of Preference by Similarity to Ideal Solution) and the Weighted Sum Model (WSM).

\subsection{TOPSIS Analysis}

TOPSIS evaluates models against five criteria:

\begin{itemize}
    \item \textbf{D/kLOC} (30\%, cost): defect density---lower is better
    \item \textbf{High\%} (15\%, cost): proportion of high-severity findings---lower is better
    \item \textbf{LOC/App} (20\%, benefit): code output volume---higher indicates more complete implementations
    \item \textbf{Out \$/Mtok} (20\%, cost): output pricing---lower is more cost-effective
    \item \textbf{I/100LOC} (15\%, cost): issues per 100 lines---lower is better
\end{itemize}
